Instagram Followers Viewer

How to get the cURL command
  1. Open the Instagram profile page in your browser (e.g. https://www.instagram.com/username/)
  2. Right-click and choose Inspect
  3. Open the Network tab
  4. Type followers in the Network filter box
  5. Click the Followers button on the profile
  6. A request to /api/v1/friendships/…/followers/ will appear — right-click it
  7. Choose Copy → Copy as cURL
  8. Paste the result below
